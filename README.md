# Shorts AI — Privacy Policy

This repository contains the public privacy policy for **Shorts AI**, a browser extension for creating vertical short-form videos.

## About Shorts AI

Shorts AI helps users transform videos they provide into vertical short-form videos suitable for platforms such as YouTube Shorts.

The extension is designed to perform video processing locally on the user's computer, minimizing the need to upload video content to external servers.

## Data & Privacy

Shorts AI is designed with a local-processing approach.

* Video processing is performed locally where supported.
* Video files are not uploaded to a Shorts AI server for processing.
* The extension does not intentionally collect browsing history.
* The extension does not sell user data.
* Local settings and project state may be stored on the user's device.
* Users control the videos they provide to the extension.

For complete details, see the [Privacy Policy](privacy-policy.md).

## GitHub Pages

This repository can be used to host the privacy policy through GitHub Pages.

### Enable GitHub Pages

1. Open the repository's **Settings**.
2. Select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch.
5. Select `/ (root)` as the folder.
6. Click **Save**.

The privacy policy will then be available at:

```text
https://YOUR-GITHUB-USERNAME.github.io/shorts-ai-privacy/
```

Use that URL as the **Privacy policy URL** when publishing Shorts AI on the Microsoft Edge Add-ons Store.
